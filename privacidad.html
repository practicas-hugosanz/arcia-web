Qué datos trata el titular, para qué y cuánto tiempo

Este sitio web

  • Qué: nada más que los registros técnicos del servidor (tu dirección IP y la página pedida). No hay cookies, analítica ni formularios.
  • Para qué y con qué base: servir las páginas y protegerlas de abusos; interés legítimo.
  • Cuánto tiempo: lo que guarde GitHub, que aloja el sitio, según su política.

Buscar actualizaciones

  • Qué: la aplicación pregunta a GitHub cuál es la última versión, y GitHub ve tu dirección IP. No se manda nada más.
  • Para qué y con qué base: que tengas las correcciones; ejecución del contrato.
  • Cuánto tiempo: el titular no guarda nada de esto.

Tu licencia y tu suscripción

  • Qué: el código de tu ordenador; el nombre, el correo y los datos de pago que das en Stripe (el titular no ve el número de tu tarjeta); y qué versión de los términos aceptaste, con su fecha y la huella del texto.
  • Para qué y con qué base: darte la licencia, cobrarla, facturarla y poder demostrar lo que se acordó; ejecución del contrato y obligaciones legales de facturación.
  • Cuánto tiempo: mientras dure la suscripción y, después, lo que exige la ley para las facturas (seis años) y mientras puedan reclamarse responsabilidades del contrato.

Una prueba gratuita por persona

  • Qué: tu correo, sin puntos ni añadidos, y una huella de tu tarjeta que da Stripe (no es el número y no sirve para cobrar).
  • Para qué y con qué base: que la prueba gratuita no se repita con otra cuenta; interés legítimo.
  • Cuánto tiempo: mientras Arcia ofrezca prueba gratuita. Puedes pedir que se borre, sabiendo que entonces no se podrá comprobar si ya la tuviste.

Si pulsas «Enviar a soporte»

  • Qué: el informe de diagnóstico, que la aplicación te enseña entero antes de enviarlo: la versión, cómo tienes configurada la app, recuentos y las últimas líneas del registro, que pueden llevar direcciones web. Además, tu nombre, el correo de tu licencia y el código de tu ordenador, para contestarte. No lleva claves, contraseñas ni tu lista de leads.
  • Para qué y con qué base: resolver tu consulta; ejecución del contrato (el soporte está incluido).
  • Cuánto tiempo: hasta doce meses después de resolverla.
